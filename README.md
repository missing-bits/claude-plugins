# Missing Bits — Claude Code Plugins

Marketplace of [Claude Code](https://code.claude.com) plugins by Missing Bits.

## Installation

```bash
# Add the marketplace (one-time)
/plugin marketplace add missing-bits/claude-plugins

# Install a plugin
/plugin install <plugin>@missing-bits
```

## Plugins

| Plugin | Description |
|--------|-------------|
| `working-process` | Spec-driven working process: grilling-session and architect-session skills, architect and plan-adversary review agents |
