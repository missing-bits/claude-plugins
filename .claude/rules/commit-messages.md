# Commit messages

- One line only: a single conventional-commit subject, no body paragraph.
- Conventional-commit prefix: `type:` or `type(scope):` — e.g. `docs:`,
  `chore:`, `fix(working-process):`.
- Public-repo hygiene applies to the subject too — see the
  [repo-hygiene](./repo-hygiene.md) rule (no machine paths, no company or
  client names, English only).
